# pub

Short links for sources cited in Switchbox reports, served at `https://pub.switch.box/<citekey>` by GitHub Pages.

`links.json` maps each citation key to its destination and is the source of truth. `404.html` embeds the same map and forwards the reader, so every key works without its own page. Both files are written by the reports2 source-ingest tooling; don't edit them by hand.
